# Скриншоты BioFlow

Здесь лежат изображения для раздела «Скриншоты» в [README](../README.md).

## Как заменить заглушки на настоящие скриншоты

1. Сделай скриншоты своего приложения (лучше на тёмной теме, без личных данных).
2. Обрежи их до **1080 × 1920** (вертикальные, 9:16) и сохрани как PNG.
3. Положи файлы в эту папку с **теми же именами**, что и заглушки:

   | Файл | Что на нём |
   |---|---|
   | `01-dashboard.png` | Главный экран (дашборд) |
   | `02-biometrics.png` | Экран биометрии |
   | `03-journal.png` | Дневник «7 минут» |
   | `04-stats.png` | Статистика / аналитика |
   | `05-settings.png` | Настройки |

4. Закоммити и запушь изменения — README подхватит картинки сам, править его не нужно.

> Если захочешь добавить шестой экран — просто положи рядом файл `06-что-то.png`
> и допиши в README ещё одну ячейку в таблицу.

## Как перегенерировать заглушки

В корне репозитория лежит скрипт `make_placeholders.py` (нужен Python с Pillow):

```bash
python make_placeholders.py
```

Он пересоздаст все пять заглушек в текущем оформлении приложения.
